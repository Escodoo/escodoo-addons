Custom Sale Addon for Client-specific Solution.

This module automatically grants portal access to partners when a sale order is confirmed, sending an invitation email if the partner doesn't already have portal access.

.. contents::

Usage
=====

Usage
=====

When a sale order (quotation) is confirmed, the system will:

1. Check if the partner already has portal access
2. If not, automatically grant portal access to the partner
3. Send an invitation email to the partner with portal access credentials

The partner must have a valid email address for the portal invitation to be sent.
