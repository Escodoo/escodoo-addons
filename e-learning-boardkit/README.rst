Usage
=====

=====
Usage
=====

Para utilizar este módulo:

#. Acesse o menu **eLearning** no Odoo.
#. Abra o canal **Boardkit Course** (criado pelos dados demo do módulo).
#. Siga os 12 capítulos, lendo o conteúdo rich HTML de cada lição.
#. Responda os quizzes de capítulo para validar o aprendizado.
#. Realize o **Survey de Certificação** ao final do curso.
#. Baixe o certificado PDF gerado no formato *Escodoo Portrait A4*.
#. Valide o certificado publicamente escaneando o QR code impresso no
   documento.
