Public website for Escodoo, an Odoo consultancy specialised in Odoo Community,
the OCA ecosystem and the Brazilian fiscal localisation.

Ships the whole corporate site as editable website builder pages: solutions
grouped by the buyer's situation, the service lines, seven industry pages, the
positioning hub that argues for Community plus OCA, anonymous result cases, the
international service lines and a conversion layer that feeds the CRM.

The feature assessment behind the feature map, the edition comparison and the
industry pages is stored on records rather than repeated in page markup, so the
module that closes a given gap is named once and cited everywhere.
